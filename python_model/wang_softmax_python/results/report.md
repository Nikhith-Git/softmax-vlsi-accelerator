## Limitations of this evaluation

- Software-model accuracy only; nothing here is measured hardware behaviour.
- d1, d2, all fixed-point formats and the pass-1 lnF = 0 are provisional/experimental, not paper values; results describe THESE settings.
- Random inputs are synthetic (uniform / normal logits), not logits from a trained network.
- The a-priori envelope is conservative (independent interval combination), so passing it is a sanity check, not a tight accuracy claim.
- Only the default rounding/overflow (trunc, saturate) is evaluated on the main grid; rounding mode is compared only in the precision sweep.
